# 香港路牌駕駛練習（3D 小遊戲）

瀏覽器版 **Three.js** 3D 模擬駕駛，專為 **學車／考車牌** 認識香港常見交通標誌而設。

🎮 **線上遊玩：** https://danielshtong.github.io/hk-driving-signs/

## 點樣玩

1. 打開網頁，按「開始駕駛」
2. 用鍵盤或螢幕按鈕開車，沿迷你道路行駛
3. 接近路牌時會暫停並出現測驗——選正確做法
4. 答對加分；答錯會顯示簡短提示，方便溫習
5. 完成所有路牌測驗即完成本輪練習

### 操作

| 動作 | 鍵盤 | 手機／平板 |
|------|------|------------|
| 加速 | `W` 或 `↑` | 螢幕 ▲ |
| 剎車／倒車 | `S` 或 `↓` | 螢幕 ▼ |
| 左轉／右轉 | `A`／`D` 或 `←`／`→` | 螢幕 ◀ ▶ |

## 學習目標

練習辨認並正確回應香港考車牌常見路牌，包括：

- 停車讓行、讓路
- 不准駛入、單程路
- 車速限制（50）
- 不准掉頭、不准左轉、不准超車
- 行人過路處、小心兒童／學校區域
- 前面有交通燈、前面有迴旋處

每題答完都會顯示一句實用提示（例如停車讓行要**完全停車**）。

## 技術

- 單頁 `index.html`（HTML5 + Three.js CDN）
- 路牌以 Canvas 程序繪製，無需額外圖片素材
- 適合課堂投影或學員自行練習

## 本機開啟

用任何靜態伺服器開啟本目錄，例如：

```bash
python3 -m http.server 8080
```

然後瀏覽 `http://localhost:8080`。
